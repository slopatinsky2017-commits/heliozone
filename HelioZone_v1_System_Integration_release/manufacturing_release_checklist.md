# Manufacturing Release Checklist

- [ ] Schematic review complete and signed.
- [ ] PCB DRC clean for MCPCB and control board.
- [ ] BOM AVL checked for all critical parts.
- [ ] Pick-and-place validated with assembly house.
- [ ] Gerber/drill package reviewed with fabricator.
- [ ] Harness drawings approved.
- [ ] Firmware baseline tag created.
- [ ] EVT build plan and test fixtures prepared.
