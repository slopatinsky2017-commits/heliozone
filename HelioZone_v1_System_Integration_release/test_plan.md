# Test Plan

## Electrical
- Input inrush and reverse-polarity test.
- Per-channel current accuracy test at 10/50/100% command.
- PWM linearity and low-level flicker test.

## Thermal
- 25 C ambient steady-state map at nominal 115 W.
- Elevated ambient (40 C) derating verification.

## Functional
- Logical-to-physical mapping verification.
- Fault injection: NTC open/short, output open circuit.
- Firmware recovery and safe restart behavior.
