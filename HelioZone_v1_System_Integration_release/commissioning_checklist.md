# Commissioning Checklist

- Verify no shorts between 48V and PGND before power-on.
- Program ESP32-S3 bootloader and baseline firmware.
- Confirm each physical output regulates current into dummy load.
- Connect LED board and verify channel by channel illumination.
- Validate NTC readouts and thermal throttling threshold.
- Perform 30-minute burn-in at 100% white + 30% spectral blend.
