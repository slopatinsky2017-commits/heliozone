# Fabrication Notes - Control FR4

- Layer stack: 4-layer FR4, 1.6 mm, Tg170.
- Copper: 1 oz outer, 0.5 oz inner.
- Controlled impedance not required.
- Keepout under ESP32-S3 antenna: no copper all layers.
- Thermal vias under TPS92518HV exposed pads.
- Finish: ENIG.
- Required tests: ICT for shorts/opens + functional power-up + UART smoke test.
